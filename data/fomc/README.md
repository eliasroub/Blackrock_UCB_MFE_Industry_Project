# `data/fomc/` — FOMC statement & minutes corpus (+ anonymized derivatives)

`documents.jsonl` — one JSON per line, the reference schema for every bank
corpus (`doc_id`/`doc_type`/`release_date`/`text` + provenance fields),
consumed by `FomcCorpus` (`src/data/fomc_text.py`). **343 docs: 172 statements
+ 171 minutes, 2005 → 2026.** Statements release same-day; minutes ~3 weeks
later; both keyed off their own `release_date`, so the as-of filter is
point-in-time correct for either.

## Anonymized derivatives (2026-07-29)

Generated by `src/run_anonymize.py` (Haiku `claude-haiku-4-5-20251001`,
temperature 0.0, forced tool calls; run artifacts + verify report in
`results/anonymize/`). **Statements only** — minutes are not anonymized yet.

- `statements_anon.jsonl` — the 172 statements with `text` rewritten so the
  period cannot be identified: all dates/months/years/times removed, named
  officials → role titles, named events (wars, pandemics, bank failures) →
  generic descriptions that keep the economic content, uniquely-dateable
  program names → mechanism descriptions. All non-date numbers, the policy
  decision, and the hawkish/dovish wording are preserved verbatim
  (`verify`: 0 date hits, 99.7% percent-token survival, length ratios all
  within [0.7, 1.2]).
- `excerpts_<persona>.jsonl` (×11) — per-analyst routing of the anonymized
  statements: for each of the 7 FOMC macro personas and the 4 US equity
  internals personas, the verbatim passages of each statement relevant to
  that persona's mandate (87–99% verbatim rate; the equity personas' relevance
  definitions are the curated blocks in `run_anonymize.py` — their YAML cues
  are placeholders from the features-only r7 design, and text is a NEW input
  for them).
  One row per source statement; when a statement says nothing about the
  driver, `text` is the selector's empty-context placeholder so `as_of` stays
  aligned meeting-by-meeting. Wired via each persona's `text_corpus:` field;
  intended for `--text-mode whole`.

## Caveats

- `release_date` is kept in all derived files — it is the as-of join key and
  never enters a prompt.
- Anonymization removes the cheapest tells, not the information: a 9.1% CPI
  print still identifies its quarter. The project is narrative-first; the
  recall-probe verdict (results in ../macro-llm, r8) still applies.
- These documents sit inside the model's training window (project-wide caveat,
  same as the other bank corpora).
